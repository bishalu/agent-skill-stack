### vercel

- **deploy-to-vercel, vercel-cli-with-tokens** — Deployment is already owned in this environment by the Vercel MCP server (mcp__vercel__deploy_to_vercel and friends), which is authenticated and account-aware. Installing these skills would put two owners on the deployment phase.
- **react-native-skills** — No React Native or Expo work in this environment.
- **writing-guidelines** — Vercel-house-voice prose review; no owner conflict, but nothing in this stack routes to it.

### trailofbits

- **second-opinion** — Runs an external LLM review of a diff — a third owner in the code-review domain alongside ce-code-review and the Pocock second opinion. Excluded rather than demoted.

- **property-based-testing, mutation-testing** — Would put a third voice in the testing domain alongside Compound and the Pocock TDD methodology. Genuinely useful — add deliberately if the testing strategy calls for them.

- **devcontainer-setup, open-sourcing, goal-prompt, skill-improver, testing-handbook-skills, spec-to-code-compliance, vulnerability-triage-brocards, culture-index, let-fate-decide, semgrep-rule-creator, semgrep-rule-variant-creator, claude-in-chrome-troubleshooting** — Out of scope for a general engineering lifecycle, or duplicative of skills already installed.
