# Host tools scripts/bootstrap.sh installs or checks, in order.
#
#   name      method        spec
#
# Methods:
#   uv-installer  astral's installer at the pinned version, into ~/.local/bin
#   uv-tool       `uv tool install <spec>`; spec is a PyPI requirement
#   nvm           nvm's installer at the pinned tag, into ~/.nvm
#   node          `nvm install <spec>`; nvm's default alias is left alone
#   npm-global    `npm install -g <spec>` under the pinned node (the preceding node row)
#   claude        Claude Code's native installer, into ~/.local/bin
#   system        needs sudo: only checked, and an install hint printed when missing
#
# A tool counts as present when its command is on PATH (node and pnpm: at the pinned
# version under nvm). Present tools are never upgraded, so a rerun changes nothing.
# A project that needs the pinned node ahead of nvm's default puts it on PATH in its
# gitignored .milestones/config.local.
